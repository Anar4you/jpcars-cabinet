# JPCars v1.3.3 — Версии документов

Исправлена логика замены документов.

## Как теперь работает замена

Если клиент загружает новый файл той же категории, например:
`Нотариальная выписка паспорта`

то:
1. новая загрузка становится текущей версией;
2. предыдущая версия автоматически перестаёт быть текущей;
3. клиент больше не видит старый файл в основном списке;
4. администратор видит только текущий файл в рабочем списке;
5. старые файлы доступны администратору в раскрываемом блоке `История заменённых документов`.

Файлы физически не удаляются автоматически — история сохраняется для аудита.

## Пакет для брокера

В ZIP теперь попадают только:
- текущие версии документов;
- проверенные документы клиента;
- актуальные документы, загруженные менеджером, если они не имеют статуса `Нужно заменить`.

Не попадают:
- старые версии;
- документы со статусом `Нужно заменить`;
- непроверенные клиентские документы.

## Миграция старых сделок

При первом запуске v1.3.3:
- для каждой пары `сделка + категория документа` самой новой загрузке присваивается статус текущей;
- предыдущие загрузки автоматически переходят в историю;
- версиям присваиваются номера по порядку загрузки.

Существующие файлы не удаляются.
