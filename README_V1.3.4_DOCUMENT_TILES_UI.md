# JPCars v1.3.4 — Плитки документов

Переделан раздел `Документы`.

## Что изменилось
- вместо длинного текстового перечня обязательных документов добавлены наглядные плитки;
- видно, какой документ:
  - не загружен;
  - загружен и ждёт проверки;
  - проверен;
  - требует замены;
- для загрузки документа dropdown заменён на плитки с иконками;
- длинные названия и имена файлов переносятся аккуратнее;
- список текущих документов визуально выровнен;
- мобильное отображение стало удобнее.

## Для клиента
Клиенту теперь проще понять:
- что ещё нужно загрузить;
- что уже принято;
- что нужно заменить.

## Для администратора
Администратору легче видеть текущий комплект документов и отдельно историю заменённых версий.
