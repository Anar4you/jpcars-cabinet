# JPCars Cabinet v0.9 — Security Hardening

Версия для более безопасного онлайн-тестирования.

## Добавлено

- постоянное SQLite-хранилище админских сессий на `DATA_DIR`;
- сессии больше не используют стандартный Express MemoryStore;
- secure + httpOnly + SameSite cookies в production;
- Helmet security headers;
- ограничение попыток входа в админку;
- ограничение частоты запросов к публичному кабинету;
- same-origin защита POST/PUT/PATCH/DELETE запросов от CSRF;
- строгая проверка MIME-типа и расширения файлов;
- журнал скачивания/просмотра документов, медиа и платежных файлов;
- журнал успешных и неуспешных попыток входа;
- раздел «Журнал доступа» внутри сделки менеджера;
- сохранены защищённые персональные ссылки v0.7+;
- сохранены платежи, фильтры и архив v0.8.

## Railway

Оставьте существующий Volume с mount path:

`/data`

Переменные:

- `NODE_ENV=production`
- `DATA_DIR=/data`
- `ADMIN_PASSWORD=<ваш сложный пароль>`
- `SESSION_SECRET=<случайная строка 32+ символа>`

После загрузки этой версии Railway выполнит новый deploy. База v0.8.1 будет использована автоматически, если тот же Volume `/data` остаётся подключённым.

## Важно

v0.9 заметно безопаснее предыдущей версии, но для полноценной эксплуатации с большим количеством реальных паспортных/банковских документов следующим шагом рекомендуются:
- резервное копирование;
- отдельное S3-compatible object storage для документов;
- malware/antivirus scanning;
- полноценная политика хранения/удаления персональных данных;
- 2FA для администраторов;
- несколько аккаунтов менеджеров с персональным аудитом.
