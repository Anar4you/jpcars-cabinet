# JPCars v1.3.2 — Document Review Telegram

Добавлены Telegram-уведомления клиенту при проверке документов.

## Если документ принят
Клиент получает:
- «Документ принят»;
- название/тип документа;
- комментарий менеджера, если он указан;
- кнопку перехода в личный кабинет.

## Если документ нужно заменить
Клиент получает:
- «Документ нужно заменить»;
- название/тип документа;
- комментарий менеджера;
- просьбу загрузить новый файл через личный кабинет.

## Важно
Используется существующая настройка автоуведомлений сделки.
Если Telegram клиента не подключён или автоуведомления отключены, сообщение не отправляется.

## Проверка
1. Клиент загружает тестовый документ.
2. В админке открыть документ.
3. Выбрать `Проверен`.
4. Клиент должен получить сообщение «Документ принят».
5. Затем для другого документа выбрать `Нужно заменить` и добавить комментарий.
6. Клиент должен получить Telegram с причиной замены.
