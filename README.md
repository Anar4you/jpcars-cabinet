# JPCars Cabinet v0.8

Функциональный релиз для ежедневной работы менеджера.

## Добавлено

### Платежи
- отдельные платежи по сделке;
- название и сумма;
- статус:
  - ожидается;
  - выставлено;
  - оплачено;
- комментарий;
- возможность прикрепить документ к платежу;
- клиент видит платежи и может скачать приложенный документ;
- файл платежа защищён токеном сделки или авторизацией администратора.

### Поиск и фильтры
В админке можно искать по:
- ФИО;
- телефону;
- VIN / номеру кузова;
- марке;
- модели.

Есть фильтр по стране.

### Архив
- сделку можно перенести в архив;
- архив отделён от активных сделок;
- архивную сделку можно вернуть обратно.

## Перенос данных из v0.7.1
Можно скопировать:
- `data/jpcars.db`
- папку `uploads`

Новые таблицы и поля будут добавлены автоматически при первом запуске.
