# JPCars v1.3.5 — Media Upload Limit

Исправлена ошибка `File too large` при загрузке фото/видео автомобиля.

## Новые лимиты
- документы: до 30 МБ на файл;
- фото и видео автомобиля: до 150 МБ на файл;
- до 20 медиафайлов за одну загрузку.

## Разрешённые медиаформаты
- JPG / JPEG
- PNG
- WEBP
- MP4
- MOV

Ограничение документов осталось прежним.
