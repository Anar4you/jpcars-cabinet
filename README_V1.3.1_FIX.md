# JPCars v1.3.1 — Status Telegram Fix

Исправлена автоматическая отправка Telegram-уведомлений клиенту при смене этапа сделки.

## Причина
В v1.3 при добавлении внутреннего центра уведомлений обработчик `/admin/update/:id`
был изменён, и вызов `sendTelegramForDeal(...)` из него исчез.

Поэтому:
- тестовое сообщение работало;
- ручное сообщение работало;
- привязка Telegram работала;
- автоматическое уведомление при смене статуса не отправлялось.

## Исправлено
- автоматическая отправка после сохранения нового статуса возвращена;
- используется актуальная запись сделки после UPDATE;
- учитывается `telegram_notifications_enabled`;
- учитывается галочка `silent_telegram`;
- отправка/пропуск/ошибка логируются;
- смена этапа снова записывается в audit.

## Проверка
1. Обновить GitHub и дождаться Railway deploy.
2. Открыть сделку с подключённым Telegram клиента.
3. Убедиться, что автоуведомления не отключены.
4. Сменить этап и НЕ ставить галочку «Не отправлять Telegram-уведомление».
5. Клиент должен получить Telegram-сообщение.
6. В Deploy Logs будет строка `Client Telegram status notification`.
