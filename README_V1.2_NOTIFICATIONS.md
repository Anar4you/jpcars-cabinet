# JPCars Cabinet v1.2 — Уведомления 2.0

## Клиентские Telegram-уведомления
- автоматическое сообщение при смене этапа;
- более человеческие формулировки для ключевых этапов;
- комментарий менеджера добавляется в уведомление;
- кнопка «Открыть кабинет»;
- менеджер может отключить автоуведомления по конкретной сделке;
- при одной смене статуса можно поставить галочку «Не отправлять Telegram-уведомление»;
- менеджер может отправить произвольное сообщение клиенту из карточки сделки;
- история отправок сохраняется.

## Telegram сотрудников
В разделе `Команда` каждый сотрудник может подключить свой Telegram.

После подключения сотрудник может получать служебные уведомления, когда клиент загружает новый документ.

Администратор может включить/отключить такие уведомления для конкретного сотрудника.

## Важно
Telegram Bot API подтверждает успешную отправку сообщения в API, но не предоставляет приложению обычный статус «прочитано клиентом». Поэтому в журнале JPCars хранится статус `отправлено/ошибка`, а не «прочитано».

## После обновления
1. Загрузить v1.2 в GitHub.
2. Дождаться Railway deploy.
3. Повторно устанавливать webhook не обязательно, если URL/secret не менялись.
4. Открыть `Команда`.
5. Подключить Telegram нужным сотрудникам.
6. Проверить загрузку тестового документа клиентом.
7. Проверить автоматическое уведомление клиента при смене этапа.
