# JPCars v1.3.6 — Массовая загрузка медиа

## Загрузка
- до 150 фото/видео за одну загрузку;
- до 150 МБ на один файл;
- JPG, JPEG, PNG, WEBP, MP4, MOV.

## Галерея
Чтобы кабинет не перегружался:
- первые 30 медиафайлов показываются сразу;
- остальные скрыты под кнопкой `Показать ещё`;
- изображения используют lazy loading.

Это рассчитано на сделки, где может быть около 100 фотографий автомобиля.
