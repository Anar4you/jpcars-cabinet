# JPCars v1.2.3 — Document Notification Fix

Исправлена ошибка:

`no such column: title`

## Причина
Таблица `documents` содержит поле `category`, а не `title`.
После успешной записи файла код пытался выполнить:

`SELECT title FROM documents ...`

Из-за этого запрос падал раньше отправки Telegram-уведомления менеджеру.

## Исправлено
- для уведомления используется реальное поле/значение `category`;
- лишний SELECT удалён;
- загрузка документа больше не зависит от успешности Telegram;
- если Telegram временно недоступен, файл всё равно сохраняется и клиент возвращается в кабинет;
- загрузка документа записывается в аудит;
- кнопка «Открыть сделку» в уведомлении добавляется только при наличии PUBLIC_BASE_URL.

## Проверка после deploy
1. Убедиться, что Telegram сотрудника подключён в «Мой Telegram».
2. Убедиться, что уведомления о документах включены.
3. Открыть клиентский кабинет.
4. Загрузить тестовый документ.
5. Клиент должен вернуться в кабинет без ошибки.
6. Менеджеру должно прийти Telegram-уведомление.
