# JPCars v1.3 — Центр уведомлений

Добавлен внутренний центр уведомлений для сотрудников.

События:
- клиент загрузил документ;
- документ проверен;
- изменён этап сделки;
- отправлено ручное Telegram-сообщение клиенту;
- добавлен платёж (если используется соответствующая форма).

В админке:
- кнопка `Уведомления`;
- счётчик непрочитанных;
- открыть связанную сделку;
- отметить одно уведомление прочитанным;
- отметить всё прочитанным.

Telegram остаётся быстрым внешним каналом, а центр уведомлений хранит события внутри JPCars.
