# JPCars v1.2.2 — «Мой Telegram»

## Что изменилось

У каждого сотрудника теперь есть персональный раздел:

`Админка → Мой Telegram`

Сотрудник сам:
- подключает свой Telegram;
- видит, какой Telegram подключён;
- отключает свой Telegram;
- включает/отключает служебные уведомления о новых документах клиентов.

## Раздел «Команда»

Администратор:
- видит, подключён Telegram у сотрудника или нет;
- видит username, если он доступен;
- может управлять уведомлениями о документах;
- больше не подключает Telegram за сотрудника.

Это делает привязку аккаунтов понятнее и безопаснее: каждый менеджер подключает только свой Telegram.
