# JPCars Cabinet v1.1 — Telegram Notifications

## Как работает

Клиент открывает свой личный кабинет и нажимает **«Подключить Telegram»**.

Ссылка открывает Telegram-бота JPCars с параметром конкретной сделки. После `/start` сервер сохраняет `chat_id` Telegram в этой сделке.

После этого при изменении этапа автомобиля менеджером клиент автоматически получает сообщение в Telegram.

Сообщение содержит:
- автомобиль;
- новый этап;
- комментарий менеджера (если есть);
- кнопку **«Открыть кабинет»**.

## Railway Variables

Добавьте:

`TELEGRAM_BOT_TOKEN=<токен от BotFather>`

`TELEGRAM_BOT_USERNAME=<username бота без @>`

`TELEGRAM_WEBHOOK_SECRET=<случайная секретная строка>`

`PUBLIC_BASE_URL=https://ваш-домен`

Например PUBLIC_BASE_URL:
`https://jpcars-production.up.railway.app`

## Настройка

1. Создать бота через `@BotFather`.
2. Получить token.
3. Задать username бота.
4. Добавить 4 Railway Variables.
5. После deploy войти администратором.
6. Открыть раздел **Telegram**.
7. Нажать **«Установить webhook»**.
8. Открыть тестовую сделку.
9. В кабинете клиента нажать «Подключить Telegram».
10. В Telegram нажать Start.
11. В админке сделки нажать «Отправить тест».
12. Изменить этап сделки и проверить автоматическое уведомление.

## Безопасность webhook

Если задан `TELEGRAM_WEBHOOK_SECRET`, приложение проверяет заголовок
`X-Telegram-Bot-Api-Secret-Token`.

## База

В существующую базу автоматически добавятся:
- Telegram chat ID;
- username/имя клиента;
- дата подключения;
- журнал отправленных уведомлений.

Существующие сделки и документы сохраняются при использовании того же Railway Volume `/data`.
