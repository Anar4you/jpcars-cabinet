# JPCars v1.2.1 — Staff Telegram Fix

Исправлено подключение Telegram сотрудников.

## Причина
Сотруднику передавался deep-link параметр вида `staff_1`.
Обработчик `/start` требовал параметр длиной минимум 8 символов.
`staff_1` содержит 7 символов, поэтому параметр не распознавался.

## Исправление
Минимальная длина start-параметра снижена до 1 символа.
Клиентские токены продолжают работать как раньше.

После deploy:
1. Открыть Админка → Команда.
2. Нажать «Подключить Telegram» напротив сотрудника.
3. Нажать Start в боте.
4. Бот должен ответить: «Telegram сотрудника JPCars подключён».
